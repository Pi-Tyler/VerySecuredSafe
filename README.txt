КАК ОПУБЛИКОВАТЬ САЙТ НА GITHUB PAGES

1. Создай новый публичный репозиторий на GitHub.
2. Загрузи в корень репозитория два файла:
   - index.html
   - Поздравляю!.png
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку main и папку /(root), затем нажми Save.
6. После публикации GitHub покажет адрес сайта вида:
   https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/

На странице нужно ввести пароль:
Варенье-очень-вкусное

После проверки появится «С днём рождения» и начнётся скачивание
файла «Поздравляю!.png».

ВАЖНО
Пароль хранится в JavaScript-коде страницы. Это не настоящая защита
файла: человек, который умеет смотреть исходный код сайта, сможет его
найти. Такой вариант подходит для сюрприза, но не для секретных данных.
